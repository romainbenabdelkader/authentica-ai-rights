# Contributing

This repository publishes the AUTHENTICA AI Rights & Origin Manifest — an open
JSON-LD profile for content origin, rights reservation and AI/TDM opt-out.

Contributions are welcome via GitHub Issues and Pull Requests.

## Scope

In scope:
- the JSON-LD context, JSON Schema and examples
- origin, rights and AI-training signals
- validation

Out of scope:
- DRM, surveillance, watermarking, fingerprinting
- legal-decision or enforcement systems

## How to contribute

- Open an Issue to discuss ideas or report problems
- Submit a Pull Request for concrete proposals
- Keep examples consistent with the schema:
  `python3 scripts/validate_examples.py`
